# First Real Master Character Mission

Run this only after Session Zero is complete and the live provider smoke test has succeeded inside a real enforced budget.

## Directive

Create a verified Siteupfit audit and improvement proposal for one real business selected by the Master.

This directive must enter through the normal general-purpose Master command interface. No Siteupfit-specific control path may be added to the kernel.

## Constraints

- Do not contact the business.
- Do not publish anything.
- Do not purchase anything.
- Do not use payment, messaging, or social-account credentials.
- Use only approved research and file tools.
- Record every model call, tool call, cost, failure, assumption, source, artifact, and decision.
- Mark inference separately from verified fact.

## Required dependency chain

1. Research and evidence collection
2. Audit and improvement proposal
3. Independent evaluation

The mission must complete the three-task chain without manual database repair or source-code intervention.

## Success criteria

1. A source-backed assessment of the selected business and website exists.
2. A practical before-and-after improvement proposal exists.
3. Unsupported claims are removed or clearly marked.
4. All outputs are saved in the mission workspace.
5. The final evaluator returns `pass`, `revise`, or `reject` with evidence.
6. Every call and cost is recorded.
7. The task chain survives normal runtime execution and dependency transitions.

## Failure criterion

If the three-task dependency chain cannot finish without manual repair, halt higher-level feature work and return to runtime integrity.
